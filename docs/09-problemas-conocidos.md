# Problemas conocidos

| Problema | Cómo se reproduce | Impacto | Historia relacionada |
|---|---|---|---|
| Los correos de los avisos no se envían a un buzón real: el proveedor actual (`EnviadorCorreoLog`) solo registra el envío en el log del backend y marca el correo como ENVIADO. Los avisos sí llegan a la campana. | Generar un aviso con correo (por ejemplo, reservar una mesa) y revisar el log del backend: aparece `Correo para <correo>: <asunto>` y no llega ningún correo. | Medio | H15, H25, H26, H27 |
| El recordatorio de la reservación puede llegar hasta un minuto después de cumplirse las 2 horas antes del inicio, porque la tarea programada corre cada minuto. | Reservar con más de 2 horas de anticipación y esperar el recordatorio. | Bajo | H26 |
| La campana actualiza el contador cada 30 segundos, así que un aviso nuevo puede tardar hasta 30 segundos en verse si no se abre el panel. | Con la sesión abierta, marcar listo un pedido para llevar desde cocina y mirar la campana del cliente. | Bajo | H25, H27 |
| El contador de alertas de inventario se actualiza cada 60 segundos, así que una alerta generada desde otra sesión puede tardar hasta 60 segundos en verse. En la sesión que registra el movimiento se actualiza al instante. | Con dos sesiones de gerente abiertas, registrar en una una salida que deje un insumo bajo el mínimo y mirar el contador en la otra. | Bajo | H15 |
| La pantalla **Por entregar** del mesero no se actualiza en tiempo real: los platillos que cocina marca como listos aparecen al recargar o al usar **Reintentar**. | Con la pantalla abierta, marcar listo un platillo desde cocina. | Bajo | H08 |
| El botón de reembolso no se muestra en la interfaz, aunque el backend cuenta con la funcionalidad para procesar reembolsos. | Realizar un pago, confirmarlo y acceder al detalle de la transacción. La opción de reembolso no aparece disponible. | Medio | H16 |
| La pantalla de reembolsos no fue implementada debido al tiempo limitado disponible durante la etapa final del desarrollo. | Iniciar sesión con un rol autorizado para gestionar reembolsos e intentar acceder a la pantalla correspondiente. No existe una interfaz para consultar y ejecutar estas operaciones. | Medio | H16 |
| La pantalla de cobro del mesero muestra un error 404 (página no encontrada), impidiendo acceder al proceso de pago de los pedidos de mesa. | Iniciar sesión como mesero, seleccionar un pedido de mesa e intentar acceder a la pantalla de cobro. El sistema muestra un error 404 en lugar de cargar la interfaz de pago. | Alto | H16 |
| `npm ci` falla con npm 10 (el que trae Node 22) porque el `package-lock.json` se generó con npm 11: "Missing: typescript@5.9.3 from lock file". | Con Node 22 y su npm por defecto, correr `npm ci` en el backend. | Bajo. Se resuelve con `npm install -g npm@11`. | H35 |
| El plan gratuito de Supabase pausa el proyecto tras 7 días sin actividad; mientras está pausado, la API no puede conectarse a la base. | Dejar el proyecto sin uso una semana y abrir la app. | Medio. Se reactiva desde el panel de Supabase. | H35 |
