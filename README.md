# Los Burle

Plataforma web para el sistema de gestión de restaurantes: los clientes consultan el menú, reservan mesa y hacen pedidos para llevar; los meseros toman pedidos de mesa, la cocina los prepara y la gerencia administra el menú y consulta las ventas.
